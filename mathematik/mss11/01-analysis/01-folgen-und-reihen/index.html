Folgen und Reihen

Ein Selbstlernpfad: von der Zahlenfolge über ihren Grenzwert bis zur unendlichen Summe, die trotzdem endlich ist. Jeder Abschnitt leitet sein Ergebnis an einer beweglichen Darstellung her, rechnet es nach und endet mit einer Kontrollfrage. Am Schluss stehen sechzehn Übungsaufgaben auf vier Stufen, die du hier auf der Seite löst.

Worum geht es hier?

Ein Ball springt nach jedem Aufprall auf drei Viertel seiner Höhe zurück. Wie hoch springt er beim zehnten Mal? Hört er irgendwann auf? Und welchen Weg legt er insgesamt zurück — unendlich viele Sprünge, aber vielleicht doch eine endliche Strecke? Solche Fragen handeln von Folgen: Zahlen, die der Reihe nach entstehen. Am Ende kannst du:

  • eine Folge explizit und rekursiv angeben und ihren Graphen als Punktmenge zeichnen
  • arithmetische und geometrische Folgen erkennen und ihr n-tes Glied berechnen
  • eine Folge auf Monotonie und Beschränktheit untersuchen — und begründen, warum das für alle n gilt
  • mit dem ε-Streifen erklären, was lim aₙ = g bedeutet, und zu einem ε das passende n₀ bestimmen
  • Partialsummen arithmetischer und geometrischer Folgen mit einer Formel berechnen und beide Formeln herleiten
  • den Wert einer unendlichen geometrischen Reihe angeben — und erkennen, wann eine Reihe nicht konvergiert

1. Was ist eine Folge?

Eine Folge ordnet jeder natürlichen Zahl n = 1, 2, 3, … eine Zahl aₙ zu: das erste, zweite, dritte … Glied. Man kann sie auf zwei Arten angeben. Explizit steht aₙ als Term in n da — man setzt n ein und ist fertig. Rekursiv stehen der Anfang und eine Regel da, wie man vom Vorgänger zum Nachfolger kommt. Wähle eine Folge und ein n.

Folge Eine Folge (aₙ) ist eine Funktion, die jeder natürlichen Zahl n ≥ 1 eine reelle Zahl aₙ zuordnet. aₙ heißt das n-te Glied, n sein Index.
Explizit: aₙ ist ein Term in n, z. B. aₙ = 2n − 1.   Rekursiv: Anfangsglied und Bildungsregel, z. B. a₁ = 1, an+1 = aₙ + 2.
Achtung — der Graph einer Folge ist keine Linie Zwischen n = 2 und n = 3 gibt es kein Glied a2,5. Der Graph besteht aus einzelnen Punkten (n | aₙ). Wer sie verbindet, behauptet Werte, die es gar nicht gibt.

💡 Rekursiv ist oft die natürlichere Beschreibung — „jedes Jahr kommen 2 % dazu“, „jede Zahl ist die Summe der beiden davor“. Aber um a₁₀₀ zu bekommen, braucht man rekursiv alle 99 Vorgänger. Deshalb sucht man gern eine explizite Darstellung. Für die Fibonacci-Zahlen gibt es eine — die Formel von Binet —, sie enthält aber √5 und ist weit weniger handlich als die Regel.

2. Arithmetische und geometrische Folgen

Zwei Bildungsregeln kommen so oft vor, dass sie eigene Namen haben. Bei einer arithmetischen Folge kommt in jedem Schritt dieselbe Zahl d dazu, bei einer geometrischen wird in jedem Schritt mit derselben Zahl q multipliziert. Wie kommt man von a₁ direkt zu aₙ? Zähle die Pfeile.

Arithmetische und geometrische Folge Arithmetisch: an+1 − aₙ = d für alle n  ⟹  aₙ = a₁ + (n − 1) · d
Geometrisch: an+1 : aₙ = q für alle n (a₁ ≠ 0, q ≠ 0)  ⟹  aₙ = a₁ · qn−1
n Glieder, aber nur n − 1 Schritte: Von a₁ bis aₙ kommt d genau (n − 1)-mal dazu, q genau (n − 1)-mal als Faktor.
Beispiel Eine arithmetische Folge hat a₃ = 11 und a₇ = 23. Von a₃ nach a₇ sind es 4 Schritte, also 4 · d = 12, d = 3, und a₁ = 11 − 2 · 3 = 5. Damit ist aₙ = 5 + (n − 1) · 3 = 3n + 2.
Eine geometrische Folge hat a₂ = 6 und a₄ = 24: zwei Schritte, q² = 4, also q = 2 oder q = −2 — beide Folgen passen.

💡 Arithmetische Folgen sind lineare Funktionen, nur an den Stellen 1, 2, 3, … abgelesen: d ist die Steigung. Geometrische Folgen sind Exponentialfunktionen, q ist der Wachstumsfaktor. Ein negatives q lässt die Glieder abwechselnd das Vorzeichen wechseln — man nennt solche Folgen alternierend.

3. Monotonie und Beschränktheit

Zwei Fragen an jede Folge: Wird sie immer größer (oder immer kleiner)? Und gibt es eine Zahl, über die sie nie hinauskommt? Die Zeichnung zeigt nur endlich viele Glieder — sie kann einen Verdacht wecken, aber nichts beweisen. Bewiesen wird mit der Differenz an+1 − aₙ und mit einer Abschätzung, die für alle n gilt. Verschiebe die beiden Schranken.

Monotonie und Beschränktheit (aₙ) heißt monoton steigend, wenn an+1 ≥ aₙ für alle n gilt, und monoton fallend, wenn an+1 ≤ aₙ für alle n gilt (mit > bzw. <: streng monoton).
(aₙ) heißt nach oben beschränkt, wenn es eine Zahl S gibt mit aₙ ≤ S für alle n (S heißt obere Schranke), und nach unten beschränkt mit einer unteren Schranke s: aₙ ≥ s für alle n. Beides zusammen: beschränkt.
Beispiel: aₙ = (n − 1)/n an+1 − aₙ = nn + 1 − n − 1n = n² − (n − 1)(n + 1)n(n + 1) = 1n(n + 1) > 0 — also streng monoton steigend, für jedes n.
aₙ = 1 − 1n < 1 für alle n, und aₙ ≥ a₁ = 0: beschränkt durch s = 0 und S = 1.
Achtung — ein paar Glieder beweisen nichts Die ersten zehn Glieder können steigen und das elfte trotzdem kleiner sein. „Sieht steigend aus“ ist eine Vermutung; erst die Rechnung an+1 − aₙ > 0 für alle n ist eine Begründung. Die Bilanz unten prüft deshalb die Schranken gegen den genauen kleinsten und größten Wert der Folge — nicht gegen die gezeichneten Punkte.

4. Der Grenzwert einer Folge — der ε-Streifen

Die Folge aₙ = (2n + 1)/n kommt der 2 immer näher, erreicht sie aber nie. Was heißt „immer näher“ genau? Lege einen Streifen der Breite ε über und unter die 2. Egal wie schmal du ihn machst: Ab einem bestimmten Glied an₀ liegen alle weiteren Glieder darin — nur endlich viele bleiben draußen. Genau das bedeutet Konvergenz.

Grenzwert einer Folge Eine Zahl g heißt Grenzwert der Folge (aₙ), wenn es zu jedem ε > 0 einen Index n₀ gibt, so dass
|aₙ − g| < ε   für alle n ≥ n₀.
Man schreibt limn→∞ aₙ = g und sagt: (aₙ) konvergiert gegen g. Eine Folge mit dem Grenzwert 0 heißt Nullfolge. Eine Folge ohne Grenzwert heißt divergent.
Beispiel: n₀ ausrechnen aₙ = (2n + 1)/n = 2 + 1n, also |aₙ − 2| = 1n. Gesucht sind alle n mit 1n < ε, das heißt n > 1ε. Für ε = 0,01: n > 100, also n₀ = 101. Für jedes noch so kleine ε findet sich so ein n₀ — der Grenzwert ist 2.
Wichtige Nullfolgen — und die Grenzwertsätze (1/n), (1/n²), (1/√n) und (qⁿ) mit |q| < 1 sind Nullfolgen. Konvergieren (aₙ) gegen a und (bₙ) gegen b, dann konvergiert
(aₙ ± bₙ) gegen a ± b,   (aₙ · bₙ) gegen a · b,   (aₙ : bₙ) gegen a : b (falls b ≠ 0 und alle bₙ ≠ 0).
So erledigt man Brüche: 3n² + n2n² − 5 = 3 + 1/n2 − 5/n² → 32. Man kürzt durch die höchste Potenz von n und lässt die Nullfolgen verschwinden.
Achtung — „kommt immer näher“ reicht nicht Auch aₙ = 1/n kommt der Zahl −1 immer näher — trotzdem ist −1 nicht der Grenzwert, denn der Abstand wird nie kleiner als 1. Es kommt nicht auf „näher“ an, sondern auf „beliebig nah, und dann für immer“.

5. Reihen: die Summe einer arithmetischen Folge

Addiert man die Glieder einer Folge der Reihe nach, entsteht eine neue Folge: die Partialsummen s₁ = a₁, s₂ = a₁ + a₂, s₃ = a₁ + a₂ + a₃, … Diese Folge (sₙ) heißt Reihe. Für eine arithmetische Folge gibt es einen Trick, der den Schüler Gauß berühmt gemacht hat: Jedes Glied ist eine Säule. Eine zweite Kopie der Treppe, um 180° gedreht, passt genau auf die erste — zusammen bilden sie ein Rechteck.

Summenformel der arithmetischen Folge Erstes und letztes, zweites und vorletztes Glied … ergeben jeweils dieselbe Summe a₁ + aₙ. Zwei Treppen bilden deshalb ein Rechteck aus n Säulen der Höhe a₁ + aₙ:
2 · sₙ = n · (a₁ + aₙ)  ⟹  sₙ = n · (a₁ + aₙ)2 = n · a₁ + n · (n − 1)2 · d
Beispiel: 1 + 2 + … + 100 n = 100, a₁ = 1, a₁₀₀ = 100: s₁₀₀ = 100 · 101 : 2 = 5050. Die gerade Zahlen 2 + 4 + … + 100: n = 50, s₅₀ = 50 · (2 + 100) : 2 = 2550.

💡 Warum ist a₁ + aₙ = a₂ + an−1? Das zweite Glied ist um d größer als das erste, das vorletzte um d kleiner als das letzte — die Summe bleibt gleich. In der Zeichnung heißt das: Jede gedrehte Säule füllt die Lücke über ihrem Gegenstück genau bis zur selben Höhe.

6. Die Summe einer geometrischen Folge

Bei einer geometrischen Folge hilft das Drehen nicht. Ein anderer Trick hilft: Multipliziere die ganze Summe sₙ mit q. Dann entstehen fast dieselben Summanden — nur um eine Stelle verschoben. Schiebe die untere Zeile nach rechts und sieh zu, was beim Abziehen übrig bleibt.

Summenformel der geometrischen Folge sₙ − q · sₙ = a₁ − a₁ · qⁿ, also (1 − q) · sₙ = a₁ · (1 − qⁿ). Für q ≠ 1 folgt
sₙ = a₁ + a₁q + … + a₁qn−1 = a₁ · 1 − qⁿ1 − q = a₁ · qⁿ − 1q − 1
Für q = 1 sind alle Glieder gleich, und sₙ = n · a₁.
Beispiel: das Schachbrett Auf das erste Feld ein Reiskorn, auf jedes weitere doppelt so viele: a₁ = 1, q = 2, n = 64. s₆₄ = (2⁶⁴ − 1) : (2 − 1) = 2⁶⁴ − 1 ≈ 1,8 · 10¹⁹ Körner — mehr Reis, als je geerntet wurde.

7. Die unendliche geometrische Reihe

Was passiert mit sₙ = a₁ · (1 − qⁿ)/(1 − q), wenn n immer größer wird? Ist |q| < 1, dann ist (qⁿ) eine Nullfolge (Abschnitt 4) — der Summand qⁿ im Zähler verschwindet, und die Partialsummen streben gegen einen festen Wert. Unendlich viele Summanden, aber eine endliche Summe. Beobachte, wie die Lücke bis zur Summe schrumpft.

Unendliche geometrische Reihe Für |q| < 1 konvergiert die Reihe a₁ + a₁q + a₁q² + …, und ihr Wert ist
s = limn→∞ sₙ = a₁1 − q.    Der Abstand ist s − sₙ = a₁ · qⁿ1 − q.
Für |q| ≥ 1 (und a₁ ≠ 0) divergiert sie.
Beispiel: periodische Dezimalzahlen 0,3 = 0,3 + 0,03 + 0,003 + … mit a₁ = 0,3 und q = 0,1: s = 0,3 : 0,9 = 13.
0,9 = 0,9 : 0,9 = 1 — kein „fast 1“, sondern genau 1. Und 0,27 = 0,27 : 0,99 = 2799 = 311.

8. Stolperstelle: Die Summanden werden klein — und trotzdem keine Summe

Lena meint: „Bei 1 + 12 + 13 + 14 + … werden die Summanden immer kleiner und gehen gegen 0. Also muss die Summe irgendwann aufhören zu wachsen.“ Die Zeichnung fasst die Summanden zu Blöcken zusammen: 1/2, dann 1/3 + 1/4, dann 1/5 bis 1/8, dann 1/9 bis 1/16 … Jeder Block ist mindestens so groß wie die gestrichelte Hälfte.

Achtung — eine Nullfolge als Summanden genügt nicht Der Block von 1/(2k−1 + 1) bis 1/2k hat 2k−1 Summanden, jeder mindestens 1/2k — zusammen mindestens 12. Nach k Blöcken ist die Summe also mindestens 1 + k/2, und das wächst über jede Grenze. Die harmonische Reihe 1 + 1/2 + 1/3 + … divergiert. Damit eine Reihe konvergiert, müssen die Summanden gegen 0 gehen — aber das allein reicht nicht.

Innermathematische Zusammenhänge

  • Baut auf: Den linearen Funktionen — eine arithmetische Folge ist eine lineare Funktion, die man nur an den Stellen n = 1, 2, 3, … abliest; d ist die Steigung.
  • Baut auf: Den Exponentialfunktionen — eine geometrische Folge wächst oder zerfällt mit dem festen Faktor q, genau wie ein Kapital mit Zinseszins.
  • Gleiche Struktur: Der Gauß-Trick (zwei Treppen ergeben ein Rechteck) ist dieselbe Idee wie die Flächenformel des Trapezes: Zwei gleiche Trapeze ergeben ein Parallelogramm.
  • Gleiche Struktur: Der Zinseszins und die Sparrate führen auf geometrische Summen; periodische Dezimalbrüche sind unendliche geometrische Reihen.
  • Führt weiter zu: Den Grenzwerten von Funktionen — der ε-Streifen kommt dort für x → ∞ wieder, und mit Folgen xn → x₀ untersucht man, was eine Funktion an einer Stelle tut.
  • Führt weiter zu: Der Differentialrechnung — die Steigung einer Kurve ist der Grenzwert einer Folge von Sekantensteigungen.
  • Führt weiter zu: Der Integralrechnung — Flächen unter Kurven entstehen als Grenzwert von Summen immer schmalerer Rechtecke, und die Summenformeln aus diesem Thema rechnen sie aus.
